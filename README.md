MyWhoosh HD 一键汉化程序 1.1.0 — 代码检查与测试报告
日期：2026-10-29

适配范围：Windows x64 微软商店版 MyWhoosh HD 6.2.3.0。
仅此版本及对应原始主资源校验值通过时允许安装。

确认并处理的问题
1. 旧版只安装界面补丁，没有课程缓存翻译组件。
2. 旧版成功提示仅表示文件写入、校验通过，无法证明游戏实际加载补丁。
   新版分别报告界面文件校验、课程匹配及更新数量，不把文件检查当成画面验证。
3. 游戏进程检测原先只匹配单一名称。新版覆盖已知变体，同时排除安装器名称，
   防止安装器被自身进程名误拦截。
4. 有101份课程使用小写description字段，严格匹配Description会漏识别。
   已修正并加入安装、检查、恢复回归测试，写回时保持原键名大小写。
5. 课程路径可能超过260字符。新版组件使用支持长路径的Windows文件接口。
6. 新版识别已经翻译的内容，重复安装保持稳定；缓存缺失时明确提示先生成缓存。
7. 添加同用户安装互斥，避免安装与恢复程序并发修改文件。
8. 分类、课程文字独立备份与记录；课程恢复保留后续收藏等非文字状态变化，
   对已进一步修改的译文跳过恢复，以免覆盖未知修改。
9. 字体覆盖补齐并检查，安装包中不含账号、存档、资源密钥或Windows系统字体。

自动化测试
界面补丁11项：版本不匹配、同版本不同资源、载荷损坏、模拟其他用户路径安装、
重复安装、恢复与无关文件保护、重复恢复、旧补丁升级、未知同名补丁保护、
注入安装后校验失败时回滚、游戏更新后仍可停用已知补丁。
课程组件9项：仅替换顶层名称和介绍；小写字段兼容；重复安装；恢复保留收藏变化；
未知课程保护；缺失缓存；超过260字符路径安装和恢复；分类富文本与恢复；
被篡改恢复路径拒绝。
另测6种进程名称分类，以及实际EXE并发运行拒绝。

本机实际EXE验证
恢复测试：恢复1,962份课程文字并停用界面补丁，退出码0。
从英文状态重新安装：更新1,962份课程文字，退出码0。
修正小写字段后：扫描2,063份，匹配2,063份，本次补齐101份，未匹配0份。
安装器界面已渲染检查。补丁包包含37个资源条目。
测试结束时，本机保留新版汉化安装状态。

检查的边界
不能仅凭这些测试认定其他用户电脑一定能正常汉化，也不能断言已找到了每一条
历史反馈的实际原因；反馈者需提供新版诊断日志及游戏版本进一步确认。
实际踩踏、阻力、比赛、成绩上传、长期运行及后续游戏更新未在此次测试中验证。
课程介绍仍包含自动译文，部分提供校对后的中文要点，均保留英文原文。
新下载或服务器变更的课程缓存可能需要重新运行安装程序。
部分动态卡片、按钮、路线名仍可能是英文。
GitHub现有发布未在本次操作中更新。

反馈“仍是英文”时
先使用玩游戏的同一Windows账户运行安装器的“检查版本与文件”，保留其中的
版本、补丁路径、课程扫描/匹配数和日志。日志位于：
%LOCALAPPDATA%\MyWhooshChinesePatch\Logs
首次安装请先打开游戏进入训练列表生成缓存，退出游戏后再安装。
