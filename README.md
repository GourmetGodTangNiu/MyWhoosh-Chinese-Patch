# MyWhoosh Chinese Patch

适用于 **Windows 64 位微软商店版 MyWhoosh HD 6.2.3.0** 的非官方部分汉化。

当前补丁包含 689 种常用界面文字、1,182 处翻译及中文字体支持。课程名、路线名、详细说明、动态内容及部分程序内文字仍可能显示英文。

## 下载与安装

在本仓库的 Releases 页面下载安装文件。

1. 完全退出 MyWhoosh。
2. 打开单文件安装器，点击「一键安装 / 更新汉化」。
3. 看到成功提示后，从原来的游戏入口启动。

ZIP 版需完整解压，然后双击「一键安装汉化.cmd」。

## 恢复英文

先退出游戏，再运行安装器中的「恢复英文」，或从 Windows 开始菜单打开「MyWhoosh 中文补丁 - 恢复英文」。ZIP 内也提供恢复入口。

## 安装保护

- 检查游戏版本、原始主资源和补丁校验值，不匹配时停止。
- 在当前用户的游戏补丁目录安装，支持游戏位于其他盘。
- 不覆盖原始游戏资源包。
- 已识别旧汉化会先备份；不会覆盖其他来源的同名补丁。
- 安装失败会尝试回退；提供恢复英文功能。

## 验证与适用范围

安装、恢复英文、重新安装和启动显示已在制作电脑上实测；另外完成了 11 项隔离文件流程检查。尚未在第二台实体电脑运行。

实际踩踏功率、踏频、阻力、完整训练、比赛、成绩上传、长期稳定性及以后游戏更新兼容性未验证。

不适用于其他游戏版本、MyWhoosh GO、手机版或 Mac 版。

分享版的中文字形来自 Noto Sans SC，英文字形来自 Barlow/Rubik，修改后的字体使用新的内部名称。安装包内附有 SIL Open Font License 及相应版权说明。
